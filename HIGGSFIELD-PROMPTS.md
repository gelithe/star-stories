# Higgsfield prompts — the 12 companion avatars

Copy-paste, one companion at a time. Each prompt is **self-contained** (the house
style is already baked in) so you can paste it straight into Higgsfield.

**Recommended workflow (define once → reuse):**
1. Generate the **primary portrait** below for a companion.
2. Pick the best result and **register it as a Character** in Higgsfield.
3. Generate the two variations (action + face) by referencing that Character, so
   the figure stays identical.
4. Bring back, per companion: the **image URL(s)** and the **Character id** — I'll
   drop them into `assets/data/companions.json` (`assets.sheet`,
   `assets.higgsfield_character_id`, `assets.poses`).

**Settings:** aspect **2:3 portrait** for a single-figure portrait (best for
registering a character), or **3:2** if you'd rather one sheet with all poses.
Use the consistent-character / character-reference mode if offered.

**Negative prompt (paste into the negative field for every one):**
```
text, words, letters, numbers, signature, watermark, logo, frame, border, harsh black outlines, neon colours, photorealistic, 3D render, plastic, glossy, scary, fangs, sharp teeth, extra limbs, deformed
```

**Style core** (already inside each prompt — here for reference):
> children's picture-book character illustration, fine hand-drawn ink linework in warm dark-brown (#2c2416) with gold-leaf accents (#c9a227) and soft translucent watercolour washes, on warm off-white paper (#faf7f0); gentle rounded friendly forms, tender and calm, storybook; full body, centred, simple pale background, generous margin

## Bring back (for the registry)

For each companion, note:

| field | goes into `companions.json` → `assets.` |
|---|---|
| chosen portrait image URL | `sheet` |
| Higgsfield **Character id** (if you registered one) | `higgsfield_character_id` |
| action / face image URLs (optional) | `poses` (e.g. `{ "action": "…", "face": "…" }`) |

Paste them back here in any form (a list of `Name → url / character-id`) and I'll
wire them into the registry — from then on the pipeline references each avatar by
id, so the same companion appears, itself, in every book.

**Element tint** is applied per book, not baked into the sheet — add the year's
wash (Wood = new-leaf green, Fire = amber, Earth = ochre, Metal = silver,
Water = sea-teal) when rendering a specific child's scene.
